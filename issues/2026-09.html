James' Curated GitHub Newsletter, September 2026

Hey everyone - this is my monthly roundup of the GitHub updates that matter most for your teams. This September issue covers announcements through October 19, with a big focus on safer agent workflows, new application security capabilities, and better enterprise controls. If anything catches your eye or you want to dig into how it fits your environment, just let me know. Feel free to share this with your team, and you can find past issues in the archive.

Agents with guardrails

The headline this cycle is pretty simple: as we expand agent capabilities, we can keep governance moving with them. That gives teams more room to use agents without treating controls as an afterthought.

  • Local sandboxing for GitHub Copilot (GA) gives local agent workflows a secure execution boundary across Copilot CLI, the GitHub Copilot app, and VS Code sessions using Agent Host. Teams can restrict filesystem, network, credential, and tool access through developer or enterprise-managed policy. It's included with GitHub Copilot at no additional cost. Read the announcement | Review the sandbox documentation
  • Enterprise managed permissions for agent operations (GA) let administrators set shell commands, file access, and network domains to deny, ask, or allow. Local settings and saved approvals can't weaken those restrictions, and different teams can have different policies. See the managed permissions update | Review the policy reference
  • Managed settings validation and freshness enforcement help close the loop on policy deployment. GitHub added an in-product validator for malformed settings and team mappings, plus a force-refresh option that can fail closed when a client can't confirm the current policy at startup. Check the settings validator | See the enforcement updates

Copilot & AI

  • Copilot code review now covers more of the review lifecycle, including pull request approvals, API-driven requests, and configurable review effort. Organizations can also choose to bill eligible member review requests to an organization cost center instead of the member entitlement. That organization-billed path requires AI Credits paid usage, and admins can put a budget around it. See approval support | Review the API and effort update | Check billing controls
  • Copilot model choice expanded again across OpenAI, Anthropic, Google, and xAI. Since availability and premium request multipliers vary, I'd use the model comparison page as the source of truth when teams choose a default. Compare available models
  • Copilot measurement and budget workflows are getting more useful for rollout decisions. The impact dashboard now shows feature engagement, budget increase requests are generally available, and the budgets page can search and filter across products, SKUs, cost centers, organizations, and users. Explore feature engagement metrics | Review budget requests | See searchable budgets
  • Content exclusions in the Copilot app and CLI (GA) extend repository exclusion rules into two more agent surfaces. That's a useful governance check if teams are moving work out of the editor and into CLI or app-based sessions. Read the announcement | Review content exclusion setup

IDE Updates

  • VS Code agent workflows added scheduled automations and agent merge in preview, plus pull request creation, Dev Container sessions, and direct GitHub issue or pull request context. The overall direction is fewer handoffs between implementation, review, and merge. Read the September Copilot roundup | Browse VS Code release notes
  • VS Code 1.142 enterprise controls can route policy-managed sessions to Copilot Agent Host and let administrators allow Assisted permissions while blocking Allow All. The same release added canvases in preview, which give developers and agents a shared interactive surface beside chat. Read the VS Code 1.142 notes | Learn about Agent Host
  • GitHub Copilot for JetBrains added managed sandbox policy, policy diagnostics, organization and enterprise skills, managed instructions, persistent MCP tool controls, and managed default models. This is a meaningful step toward closer governance parity for teams that don't standardize on VS Code. Review managed sandboxing | See the 1.18.0 update | Browse current plugin versions
  • Visual Studio 2026 Copilot chat (PREVIEW) now has an opt-in experience built on the same Copilot SDK used by Copilot CLI and the Copilot app. That shared foundation brings more consistent agent behavior across Microsoft development environments. Read the Visual Studio release notes

Security & Compliance

  • Agentic autofix for code scanning alerts (GA) can explore relevant files, propose a fix, rerun CodeQL, and open a validated draft pull request. It's available to GitHub Code Security and GitHub Advanced Security customers on GitHub Enterprise Cloud, including data residency. It requires a Copilot billing method and consumes Code Security AI Credits plus GitHub Actions minutes. Read the GA announcement | Review the documentation
  • AI Scan for pull requests (GA) complements CodeQL across languages and frameworks that don't currently have full CodeQL coverage. Findings are advisory and don't block merges. Private and internal repositories require Code Security or Advanced Security, and scans consume Code Security AI Credits. Read the GA announcement | Review AI-powered security detections
  • Open source license compliance (GA) lets enterprises use rulesets to require dependency license checks before merge. Repositories need GitHub Code Security, and the release includes data residency support, audit events, policy APIs, and an API that agents can use to check package compliance. Read the announcement | Review license compliance setup
  • Workflow execution protections for GitHub Actions (GA) can control which actors and events start workflows, with evaluate mode for testing policy impact first. If you maintain public repositories that use pull_request_target, review the default protection before enforcement begins on November 2, 2026. Read the GA announcement | Review Actions policies
  • Secret protection updates include merge blocking when exposed secrets are detected, a context-aware detection model, and broader provider coverage for keys from Anthropic, Salesforce, and others. See merge blocking | Read about the detection model | Review provider coverage updates

Enterprise Administration

  • Enterprise Live Migrations (GA) support near-zero-downtime moves from GitHub Enterprise Server to GitHub Enterprise Cloud with data residency, including large and highly active repositories. It complements GitHub Enterprise Importer, so teams can choose the right path repository by repository. Read the announcement | Review migration guidance
  • GitHub Enterprise Server 3.22 (GA) added enterprise teams, required reviewer rules, individual ruleset bypass users, and a technical preview of Copilot CLI for disconnected environments. If you're on 3.22, the 3.22.1 and 3.22.2 security patches are the more urgent part of this update. Read the 3.22 announcement | Review the 3.22 release notes
  • External custom properties (PREVIEW) can sync repository ownership, service tier, lifecycle stage, and compliance status from a CMDB, internal developer portal, or another system of record. Those values can then drive repository views, filters, and rulesets while the external system stays authoritative. Read the announcement | Review integration guidance
  • GitHub App least-privilege permissions separate repository creation and installation management from broad repository administration. That gives platform teams a cleaner path to automate app and repository management without handing out more access than the workflow needs. Review the GitHub App updates

Platform & DevEx

  • Stacked pull requests (GA) are now available for teams that want to break work into smaller, dependent changes and review them in sequence. Read the announcement
  • GitHub Actions workflow lockfiles (PREVIEW) help teams pin and review resolved Actions dependencies. This is worth a look for platform teams tightening supply-chain controls and build reproducibility. Read the preview announcement
  • Actions runner image updates include Ubuntu 26 availability and general availability of the Xcode 27 image. CI owners should check image pins and compatibility before the next scheduled workflow update. Review Ubuntu 26 | See Xcode 27 availability

Deprecations & Migration Notices

  • Copilot model retirements: Another group of models is scheduled for retirement in mid-November. Admins should review managed defaults, pinned agents, and model-specific automation now. Review the retirement notice
  • JetBrains IDE support: GitHub Copilot now requires JetBrains IDE 2025.2 or later. Review the support update
  • Node 20 in GitHub Actions: Node 20 is no longer available, so check older actions and custom JavaScript actions for runtime dependencies. Read the deprecation update
  • macOS 14 runner image: Workflows still pinned to the macOS 14 hosted image need to move to a supported image. Review the retirement notice
